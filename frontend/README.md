## 🖥️ Frontend da Aplicação

### Tecnologias Utilizadas
React | TypeScript | Material UI | Axios | React Router DOM

---

## 📦 Sobre o Projeto

Sistema de controle de estoque desenvolvido para gerenciar produtos, categorias, clientes e pedidos, 
com autenticação de usuários e controle de acesso por perfil.

---

### 🔥 Principais Funcionalidades
- Autenticação de usuários com HTTP Only Cookie
- Controle de sessão e rotas protegidas
- Cadastro de produtos, categorias e clientes
- Integração com API REST
- Tratamento de erros e validações

---

### 🧠 Conceitos Aplicados
- Arquitetura cliente-servidor
- Componentização reutilizável
- Custom Hooks para separação de lógica
- Camada de serviços isolada para comunicação HTTP
- Tipagem estática com TypeScript
- Organização modular
- Gerenciamento de autenticação

---

### 🏗️ Infraestrutura
- Docker Compose para orquestração dos containers
- Variáveis de ambiente via `.env`
- Ambiente de produção configurável via `NODE_ENV`

---

### 📈 Diferenciais
- Integração React + NestJS
- Deploy containerizado com Docker Compose
- Estrutura escalável e modular
- Boas práticas de desenvolvimento frontend
- Tipagem completa com TypeScript
- Material UI com tema customizado
